# 🗜️ Base64 DLL Decoder & Encoder
Программа для работы с файлами `.dll`, которые хранят или скрывают данные, закодированные в формат Base64. Утилита позволяет легко упаковывать тексты и полноформатные файлы в Base64-DLL, а также извлекать их обратно.
> ⚠️ **Справка для истории:** Проект был по сути заморожен в марте 2024 года — после публикации первого релиза (v0.0.1) разработка остановилась, и о проекте забыли на долгие 2 года. В 2026 году он был вновь замечен, получил версии v0.0.2-0.0.3, затем v0.0.4, 0.0.5, 0.0.6, а теперь готовится обновление v0.0.7.
>
> 📢 **Внимание:** Начиная с версии 0.0.5, в релизах публикуются готовые .exe сборки (билды).
## 🌟 Текущие возможности (Версия 0.0.7)
Утилита работает в непрерывном режиме с удобным профессиональным интерфейсом командной строки. Доступно 5 основных функций:
* **[1] Текст -> DLL** — Классическое кодирование написанного в консоли текста в Base64 с сохранением в `.dll`.
* **[2] DLL -> Текст** — Чтение зашифрованного Base64-кода из `.dll` и извлечение его в читаемый текстовый файл (`.txt`).
* **[3] Файл -> DLL** — Превращение файла совершенно **любого формата** (картинки, документы, архивы и т.д.) в сплошной `.dll` файл.
* **[4] DLL -> Файл** — Раскодировка зашифрованного `.dll` обратно в исходный рабочий формат с полным сохранением байтов.
* **[5] Инфо о DLL** — Расширенная сводка по файлу: размер, наличие метки Base64 DLL Tool, проверка Base64-потока, примерный вес после распаковки и предполагаемый формат после декода.
## 🆕 Что добавлено в v0.0.7
* Расширено автоопределение форматов после декодирования: добавлены GIF, BMP, ICO, 7z, GZip, TAR, OGG, FLAC, старые Office-файлы и более умная проверка ZIP-подобных форматов (`docx`, `xlsx`, `pptx`, `apk`, `jar`).
* Добавлена защита от случайной перезаписи результата: можно перезаписать файл, создать уникальное имя автоматически, ввести кастомный путь вручную или отменить операцию.
* Потоковое кодирование и декодирование крупных файлов вынесено в отдельный worker-поток, чтобы основной интерфейс не блокировался тяжелой файловой операцией.
* Для файловых операций добавлен прогресс в процентах с отображением обработанного и общего размера.
* Режим **«Инфо о DLL»** обновлен без добавления отдельного пункта меню: теперь он делает больше проверок и показывает предполагаемый формат после декода.
* Исправлена обратная связь при копировании текста в буфер обмена: если копирование недоступно, программа сообщает об этом.
## 🚀 Как использовать
1. Распакуйте файлы проекта в удобную папку.
2. Убедитесь, что в системе установлен **Node.js**.
3. Двойным кликом запустите `start.bat` или запустите команду:
```bash
node main.js
```
4. Следуйте подсказкам в консольном меню.
## 🛠️ Как сбилдить .exe
> Для сборки нужен установленный **Node.js** и доступ к `npm`/`npx`. При первом запуске сборщика может понадобиться интернет, чтобы `npx` скачал необходимые бинарники Node.js для `pkg`.
### Вариант 1 — через готовый скрипт
Запустите двойным кликом:
```bat
build.bat
```
Скрипт соберет Windows-исполняемый файл:
```text
Base64_DLL_Tool.exe
```
### Вариант 2 — вручную из терминала
```bash
npx pkg main.js --targets node18-win-x64 --output Base64_DLL_Tool.exe
```
