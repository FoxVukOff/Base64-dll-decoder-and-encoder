# 🗜️ Base64 DLL Decoder & Encoder

Программа для работы с файлами `.dll`, которые хранят или скрывают данные, закодированные в формат Base64. Утилита позволяет легко упаковывать тексты и полноформатные файлы в Base64-DLL, а также извлекать их обратно.

> ⚠️ **Справка для истории:** Самая первая версия из марта 2024 года была удалена из релизов, но может быть найдена в коммитах (`v0.0.1`). Сейчас перед вами масштабный ремейк 2026 года.

## 🌟 Текущие возможности (Версия 0.0.3)

Утилита работает в непрерывном режиме с удобным цветным интерфейсом командной строки. Доступно 5 основных функций:

*   **[1] Текст -> DLL** — Классическое кодирование написанного в консоли текста в Base64 с сохранением в `.dll`.
*   **[2] DLL -> Текст** — Чтение зашифрованного Base64-кода из `.dll` и извлечение его в читаемый текстовый файл (`.txt`).
*   **[3] Файл -> DLL** — Превращение файла совершенно **любого формата** (картинки, документы, архивы и т.д.) в сплошной `.dll` файл.
*   **[4] DLL -> Файл** — Раскодировка зашифрованного `.dll` обратно в исходный рабочий формат с полным сохранением байтов.
*   **[5] Инфо о DLL (Анализатор)** — Построение краткой сводки по файлу: актуальный размер, ожидаемый вес после распаковки и базовый анализ заголовка/сигнатуры файла (Hex/ASCII).

## 🚀 Как использовать

1. Распакуйте файлы проекта в удобную папку.
2. Убедитесь, что в системе установлен **Node.js**.
3. Двойным кликом запустите `start.bat` (или запустите `node main.js` из терминала).
4. Следуйте подсказкам в консольном меню!
