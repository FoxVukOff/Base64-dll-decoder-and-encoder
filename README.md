# 🗜️ Base64 DLL Decoder & Encoder
Программа для работы с файлами `.dll`, которые хранят или скрывают данные, закодированные в формат Base64. Утилита позволяет легко упаковывать тексты и полноформатные файлы в Base64-DLL, а также извлекать их обратно.
> ⚠️ **Справка для истории:** Проект был по сути заморожен в марте 2024 года — после публикации первого релиза (v0.0.1) разработка остановилась, и о проекте забыли на долгие 2 года. В 2026 году он был вновь замечен и получил обновления.
>
> 📢 **Внимание:** Начиная с версии 0.0.5, в релизах публикуются готовые .exe сборки (билды).
## 🌟 Текущие возможности
Утилита работает в непрерывном режиме с удобным профессиональным интерфейсом командной строки. Доступно 5 основных функций:
* **[1] Текст -> DLL** — Классическое кодирование написанного в консоли текста в Base64 с сохранением в `.dll`.
* **[2] DLL -> Текст** — Чтение зашифрованного Base64-кода из `.dll` и извлечение его в читаемый текстовый файл (`.txt`). После декодирования предлагается скопировать результат в буфер обмена.
* **[3] Файл -> DLL** — Превращение файла совершенно **любого формата** (картинки, документы, архивы, аудио, видео и т.д.) в сплошной `.dll` файл. Крупные файлы обрабатываются потоково в отдельном worker-потоке.
* **[4] DLL -> Файл** — Раскодировка зашифрованного `.dll` обратно в исходный рабочий формат с полным сохранением байтов. Автоматически определяет расширение по сигнатуре файла. При наличии пароля — запросит его для расшифровки.
* **[5] Инфо о DLL** — Сводка по файлу: размер, наличие метки Base64 DLL Tool, корректность Base64-потока, примерный вес после распаковки и предполагаемый формат после декодирования. Результат можно сохранить в JSON или текстовый файл.

### Защита данных
* Атомарная запись файлов через временный файл — данные не повреждаются при аварийном завершении.
* Защита от случайной перезаписи: при конфликте имён можно перезаписать, автоматически создать уникальное имя, ввести кастомный путь или отменить операцию.
* Визуальный прогресс-бар с отображением обработанного и общего размера при работе с большими файлами.

### Защита паролем (опционально)
При кодировании можно задать пароль для шифрования Base64-потока. Без пароля декодирование работает как раньше, с паролем — только при его вводе. Пароль не является обязательным.

### Проверка целостности
При кодировании вычисляется хеш (MD5/SHA256) исходного файла и сохраняется внутри DLL. При декодировании хеш сравнивается с восстановленным файлом и результат проверки отображается пользователю.

### Автоопределение форматов
При декодировании DLL обратно в файл утилита автоматически определяет расширение по магическим байтам (сигнатуре):
- **Изображения:** PNG, JPG, GIF, BMP, ICO, WebP
- **Документы:** PDF, DOC, DOCX, XLSX, PPTX
- **Архивы:** ZIP, 7z, GZ, RAR, TAR, APK, JAR
- **Аудио/Видео:** MP3, OGG, FLAC, WAV, AVI, MP4
- **Текст:** TXT, JSON, XML
## 🚀 Как использовать
1. Распакуйте файлы проекта в удобную папку.
2. Убедитесь, что в системе установлен **Node.js**.
3. Двойным кликом запустите `start.bat` или запустите команду:
```bash
node main.js
```
4. Следуйте подсказкам в консольном меню.
## 🛠️ Как сбилдить .exe
> Для сборки нужен установленный **Node.js** и доступ к `npm`/`npx`. При первом запуске сборщика может понадобиться интернет, чтобы `npx` скачал необходимые бинарники Node.js для `pkg`.
### Вариант 1 — через готовый скрипт
Запустите двойным кликом:
```bat
build.bat
```
Скрипт соберет Windows-исполняемый файл:
```text
Base64_DLL_Tool.exe
```
### Вариант 2 — вручную из терминала
```bash
npx pkg main.js --targets node18-win-x64 --output Base64_DLL_Tool.exe
```
